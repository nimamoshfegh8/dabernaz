# دابرناز ۲٫۰ — حساب کاربری و بازی خودکار

این نسخه بخش حساب کاربری و موتور اتاق دبرنا را از حالت محلی خارج می‌کند. سرور Node.js اطلاعات حساب، نشست ورود، صف بازیکنان، کارت‌ها، شماره‌های قرعه‌کشی و برندگان را نگهداری می‌کند.

## قابلیت‌های پیاده‌سازی‌شده

- **ثبت‌نام و ورود:** نام نمایشی، ایمیل و رمز عبور؛ شناسهٔ بازیکن یکتا؛ ذخیرهٔ رمز با `scrypt` و salt اختصاصی؛ نشست تصادفی با کوکی `HttpOnly` و `SameSite=Strict`؛ خروج از حساب.
- **دبرنای چندنفره:** چهار سطح اتاق و ظرفیت ۲۰ حساب ثبت‌شده در هر سانس؛ ورود به صف، ساخت کارت در سرور، شروع خودکار با ورود نفر بیستم و اعلام تصادفی شماره‌های ۱ تا ۹۰ هر ۳ ثانیه.
- **ثبت برنده‌ها:** سرور فقط اولین برندهٔ «یک خط» و اولین برندهٔ «دبرنای کامل» را نگه می‌دارد. نام و شناسهٔ بازیکن برنده در بالای صفحه نشان داده می‌شود.
- **سنگ‌کاغذقیچی:** مسابقه تا ۳ برد با حریف تطبیقی؛ مساوی امتیاز ندارد.
- **دوز:** حریف خودکار، تشخیص برد فوری و دفاع‌های مهم؛ الگوریتم عمداً شکست‌ناپذیر نیست و نتیجهٔ برد مشخص یا تضمین‌شده‌ای ندارد.
- **ثبت آمار بازی:** تعداد بازی‌ها، بردها و امتیازهای مهارتی هر حساب روی سرور ذخیره می‌شود.

## راه‌اندازی محلی

نیازمند Node.js نسخهٔ ۱۸ یا بالاتر است؛ وابستگی خارجی لازم نیست.

```bash
npm start
```

سپس `http://localhost:8080` را باز کن. در گوشی اندروید نیز می‌توانی پروژه را در Termux اجرا کنی. در صورت اشغال بودن پورت:

```bash
PORT=8092 npm start
```

اطلاعات حساب‌ها در پوشهٔ مخفی `.private/store.json` ذخیره می‌شود. این پوشه را پاک نکن و در اختیار دیگران قرار نده؛ فایل پایگاه داده شامل اطلاعات خصوصی حساب‌هاست.

## اجرای عمومی روی اینترنت

برای اینکه افراد از دستگاه‌های مختلف به یک اتاق مشترک وصل شوند، سرور باید روی VPS یا هاست پشتیبان Node.js اجرا شود و از دامنه با HTTPS در دسترس باشد. در محیط عملیاتی، `NODE_ENV=production` را تنظیم کن تا کوکی نشست به‌صورت Secure صادر شود. برای تعیین محل داده می‌توان از `DABERNAZ_DATA_DIR` استفاده کرد.

## مواردی که هنوز فعال نیستند

- درگاه پرداخت، شارژ و برداشت پول و جایزهٔ نقدی: عمداً فعال نیستند؛ درگاه و تأیید تراکنش تهیه نشده‌اند. ورود اتاق فعلاً رایگان است.
- ایمیل تأیید ثبت‌نام و بازیابی رمز عبور: به سرویس ایمیل و تنظیمات ارسال نیاز دارند.
- این سرور برای **یک نمونهٔ Node.js** طراحی شده است. برای چند نمونهٔ هم‌زمان یا مقیاس بالا باید پایگاه دادهٔ واقعی و قفل/صف مرکزی جایگزین فایل JSON شود.
- قبل از استفادهٔ عمومی، HTTPS، پشتیبان‌گیری، محدودیت نرخ درخواست، آزمون امنیتی و بررسی الزامات قانونی محل فعالیت ضروری است.

## نکتهٔ منصفانه دربارهٔ بازی‌ها

نتایج بازی‌های مهارتی تضمین نمی‌شوند. الگوریتم حریف برای رقابت قابل‌برد تنظیم شده و نتیجه را پنهانی دست‌کاری نمی‌کند. این نسخه هیچ وعدهٔ برد، درآمد یا جایزهٔ نقدی نمی‌دهد.
