# دابرناز ۳٫۰٫۱ — حساب کاربری و بازی خودکار

این بسته برای اجرا روی **هاست معمولی cPanel دارای PHP** آماده شده و یک سرور Node.js نیز برای VPS یا هاست Node نگه داشته است. فایل‌های سایت باید مستقیماً داخل ریشهٔ دامنه قرار بگیرند.

> **راهنمای استقرار Cloudflare:** برای راه‌اندازی نسخه آنلاین روی Cloudflare Pages + D1، ابتدا فایل `README-CLOUDFLARE-FA.md` را دنبال کن. بک‌اند Pages Functions در پوشه `functions/` است و در اولین درخواست API، ساختار دیتابیس را تکمیل می‌کند؛ برای این استقرار لازم نیست SQL دیگری را دستی در Console وارد کنی.

## امکانات فعال

### حساب کاربری
- ثبت‌نام با نام نمایشی، ایمیل و رمز عبور
- ورود و خروج از حساب و بازیابی نشست هنگام بازکردن دوبارهٔ سایت
- شناسهٔ اختصاصی بازیکن
- هش رمز عبور با `password_hash` در PHP یا `scrypt` در Node.js
- ذخیرهٔ آمار بازی روی سرور و نمایش آن در حساب
- نام و ایمیل در حساب سرور نگهداری می‌شوند؛ رمز عبور خام ذخیره نمی‌شود

### دبرنا
- چهار اتاق سطح ۵۰۰۰، ۱۰۰۰۰، ۲۰۰۰۰ و ۵۰۰۰۰؛ ورود فعلاً رایگان است
- هر اتاق ۲۰ حساب واقعی و ثبت‌نام‌شده می‌پذیرد؛ بازیکن ساختگی یا دکمهٔ پرکردن صف وجود ندارد
- کارت هر بازیکن در سرور ساخته و نگهداری می‌شود
- با ورود نفر بیستم، قرعه‌کشی خودکار آغاز می‌شود
- شماره‌های ۱ تا ۹۰ بدون تکرار اعلام می‌شوند
- فقط اولین برندهٔ «یک خط» و اولین برندهٔ «دبرنای کامل» ثبت می‌شوند؛ نام و شناسهٔ هر دو در بالای صفحه نمایش داده می‌شود
- در PHP، اعلام شماره با درخواست‌های به‌روزرسانی صفحه ادامه پیدا می‌کند؛ در Node.js تایمر سمت سرور آن را اجرا می‌کند
- طبق امتیازدهی قبلی پروژه، برندهٔ یک خط ۱ بینگوکوین و برندهٔ کارت کامل ۲ بینگوکوین می‌گیرد؛ این سکه‌ها مجازی‌اند و معادل وجه نقد یا قابل برداشت نیستند

### سنگ، کاغذ، قیچی و دوز
- هر دو بازی پس از ورود به حساب در دسترس هستند
- حریف رایانه‌ای به‌صورت خودکار حرکت می‌کند؛ بازیکن در سنگ‌کاغذقیچی انتخاب خودش را انجام می‌دهد و در دوز خانهٔ موردنظر را انتخاب می‌کند
- نتایج و آمار مسابقه در حساب ذخیره می‌شود
- این بازی‌ها مهارتی و بدون شرط‌بندی یا پرداخت وجه هستند؛ احتمال برد یا تعداد برد مشخصی تضمین نمی‌شود

## نصب روی cPanel (روش پیشنهادی برای هاست PHP)

1. فایل ZIP را در `public_html` دامنه بارگذاری و همان‌جا استخراج کن.
2. دقت کن `index.html` و `api.php` مستقیماً داخل `public_html` باشند؛ نباید همهٔ فایل‌ها داخل یک پوشهٔ اضافه مثل `dabernaz_pro` قرار بگیرند.
3. در File Manager گزینهٔ **Show Hidden Files** را فعال کن و مطمئن شو فایل `.htaccess` و پوشهٔ `.private` نیز بارگذاری شده‌اند.
4. نسخهٔ PHP را روی 8.1 یا بالاتر قرار بده. افزونهٔ دیتابیس لازم نیست؛ داده‌های این نسخه در فایل خصوصی سرور ذخیره می‌شوند.
5. دامنه را با HTTPS باز کن و این نشانی را آزمایش کن: `https://YOUR-DOMAIN/api/health`
6. پاسخ درست باید JSON با `"ok":true` و `"backend":"php"` باشد. اگر بازنویسی مسیرها در هاست فعال نباشد، این نشانی جایگزین را آزمایش کن: `https://YOUR-DOMAIN/api.php?path=/api/health`؛ برنامه خودش به مسیر جایگزین وصل می‌شود.
7. از بخش حساب، یک حساب جدید بساز و سپس خارج شو و دوباره وارد شو تا ثبت‌نام و ورود را بررسی کنی.

**نکتهٔ دسترسی فایل‌ها:** اطلاعات حساب داخل پوشهٔ `.private` ذخیره می‌شوند. قانون مسدودسازی دسترسی در `.private/.htaccess` را حذف نکن و دسترسی پوشه را برای نوشتن PHP باز بگذار. پوشه نباید برای بازدیدکننده قابل دانلود باشد.

## اجرای Node.js (برای VPS یا هاست دارای Node.js)

به Node.js نسخهٔ ۱۸ یا جدیدتر نیاز است. در پوشهٔ پروژه اجرا کن:

```bash
npm start
```

سپس سایت روی پورت 8080 اجرا می‌شود. اگر پورت اشغال بود:

```bash
PORT=8092 npm start
```

پوشهٔ `.private` کنار `server.js` برای ذخیرهٔ اطلاعات ساخته می‌شود. در محیط عمومی HTTPS را فعال کن. اگر پشت پراکسی HTTPS هستی، تنظیم کوکی امن نیز باید با پراکسی هماهنگ باشد.

## محدودیت‌های صریح این نسخه

- درگاه پرداخت، شارژ/برداشت پول، ورودیهٔ پولی و جایزهٔ نقدی فعال نیستند؛ فعلاً ورود اتاق دبرنا رایگان است.
- ایمیل تأیید و بازیابی رمز عبور به سرویس ایمیل نیاز دارد و در این بسته فعال نشده است.
- پشتیبانی، تورنمنت و دعوت همراه با پاداش هنوز به سرویس‌های عملیاتی متصل نشده‌اند.
- نسخهٔ PHP برای یک هاست تک‌سرور و بار کم/متوسط است؛ برای ترافیک بالا باید از MySQL یا PostgreSQL، صف/قفل مرکزی و زیرساخت چندنمونه‌ای استفاده شود.
- پیش از فعالیت عمومی، پشتیبان‌گیری، محدودیت نرخ درخواست، بررسی امنیتی و بررسی قوانین محل فعالیت لازم است.

## عیب‌یابی سریع

- اگر `/api/health` پاسخ نداد، فایل‌ها احتمالاً در ریشهٔ اشتباه استخراج شده‌اند یا PHP روی دامنه فعال نیست.
- اگر صفحهٔ قدیمی را می‌بینی، سایت را در حالت ناشناس باز کن یا کش و دادهٔ سایت را پاک کن؛ این بسته فایل‌های سرویس‌ورکر قدیمی را نیز پاک‌سازی می‌کند.
- اگر ثبت‌نام خطای دسترسی فایل داد، مجوز نوشتن پوشهٔ `.private` را بررسی کن.
- اگر در اتاق کمتر از ۲۰ بازیکن واقعی حضور دارند، شروع خودکار انجام نمی‌شود؛ بازیکن آزمایشی برای پرکردن صف ساخته نمی‌شود.
