# نسخه اندروید دابرناز

این پروژه یک برنامه اندرویدی سبک (WebView wrapper) برای سایت رسمی دابرناز می‌سازد. رابط و بازی‌ها از آدرس HTTPS سایت بارگذاری می‌شوند؛ بنابراین برای ورود، ثبت‌نام و بازی به اینترنت نیاز است.

## ساخت APK

در GitHub پس از هر تغییر در پوشه `android/`، گردش کار **Build Dabernaz Android APK** به‌طور خودکار اجرا می‌شود.

1. وارد مخزن GitHub شو.
2. از بخش **Actions** گردش کار **Build Dabernaz Android APK** را باز کن.
3. پس از سبزشدن Build، از بخش **Artifacts** فایل `Dabernaz-Android-APK` را دریافت کن.
4. ZIP را استخراج و فایل `app-debug.apk` را روی گوشی اندروید نصب کن.

## نصب مستقیم روی گوشی

هنگام اولین نصب ممکن است Android اجازهٔ نصب برنامه از منبع مرورگر/فایل‌منیجر را بخواهد. فقط برای همان منبع اجازه بده و سپس نصب را انجام بده.

این APK نسخهٔ آزمایشی امضاشده با کلید Debug است و برای نصب مستقیم و تست مناسب است؛ نسخهٔ انتشار Play Store و کلید امضای پایدار جداگانه لازم دارد. APK به سرویس Google Play نیاز اجباری ندارد، اما خود سایت برای کارکرد حساب و بازی به اینترنت و دسترسی HTTPS نیاز دارد.

## مشخصات

- نام: دابرناز
- شناسه بسته: `app.dabernaz.club.debug`
- حداقل نسخه اندروید: Android 6.0 (API 23)
- مقصد ساخت: Android API 35
- پشتیبانی از چرخش صفحه، دکمه بازگشت، صفحه انتخاب فایل و صفحه خطای عدم اتصال
