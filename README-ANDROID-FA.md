# نسخهٔ اندروید دابرناز

برنامهٔ رسمی اندروید از پوشهٔ \`android/\` ساخته می‌شود و سایت HTTPS را داخل WebView نمایش می‌دهد. صدای شماره‌ها از همان Audio Manager و همان فایل‌های MP3 استفاده می‌کند که نسخهٔ وب استفاده می‌کند؛ هیچ موتور گفتار جداگانه‌ای در Android یا مرورگر وارد اعلام شماره‌ها نمی‌شود.

## ساخت APK

گردش کار **Build Dabernaz Android APK** در فایل \`.github/workflows/android-apk.yml\` نسخهٔ اصلی را می‌سازد. پس از تغییر فایل‌های \`android/\` یا فایل‌های اصلی سایت:

1. در GitHub وارد بخش **Actions** شو.
2. گردش کار **Build Dabernaz Android APK** را باز کن.
3. بعد از سبز شدن ساخت، Artifact با نام \`Dabernaz-Android-APK\` را دریافت کن.
4. ZIP را استخراج و \`app-debug.apk\` را روی گوشی نصب کن.

## صدای فارسی

تست تنظیمات و اعلام شماره در همهٔ اتاق‌ها با یک Audio Manager و فایل‌های ضبط‌شدهٔ Sage Woman انجام می‌شوند. APK از Web Audio API برای decode و پخش فایل‌های MP3 استفاده می‌کند؛ بنابراین صدای گوشی یا موتور گفتار WebView جایگزین صدای Sage Woman نمی‌شود.

تا وقتی هر ۹۰ فایل شماره‌ای نصب و اعتبارسنجی نشده باشند، تست فایل مرجع شمارهٔ ۴۲ کار می‌کند اما کلید اعلام خودکار اتاق‌ها فعال نمی‌شود. این رفتار عمداً جلوی مخلوط‌شدن صدای زنانه با صدای رباتی دستگاه را می‌گیرد.

## ساختار پروژه

پوشهٔ \`android/\` تنها پروژهٔ اندرویدی پشتیبانی‌شده و قابل انتشار است. پوشهٔ قدیمی \`android-app/\` یک نسخهٔ آزمایشی/بایگانی‌شده است و برای ساخت نسخهٔ فعلی استفاده نمی‌شود.

این APK برای آزمایش با امضای Debug ساخته می‌شود. انتشار در فروشگاه‌ها به کلید امضای Release پایدار و تنظیمات انتشار جداگانه نیاز دارد.
